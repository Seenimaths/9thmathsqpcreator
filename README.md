# Class X Mathematics Question Paper Studio (v18)

Installable Mobile + Desktop PWA Web App for Tamil Nadu Class X Mathematics Question Paper Studio (English & Tamil Medium).

## Key Features
- **Zero-Clip Chrome Desktop & Mobile Print Engine**: Safe A4 margins (even if Chrome Print Margins is set to None), automatic flex wrapping, and clean page breaks.
- **Part I (1-Mark) Answer Key**: Clean Option Code + Answer only table (detailed working removed).
- **Part II, III, IV Detailed Solutions**: Step-by-step solutions in a crisp **two-column split** with equations neatly aligned at `=`.
- **Hybrid KaTeX + MathJax v3**: Fast KaTeX rendering with automatic MathJax v3 fallback for complex TeX expressions.
- **Auto-Installable PWA**: Ready for instant deployment on GitHub Pages, Netlify, or Vercel with offline caching and automatic install prompt.

## Deploy
- **GitHub Pages**: Upload all files to a repository and enable GitHub Pages on the `main` branch.
- **Netlify / Vercel**: Drag and drop this folder (or connect the GitHub repo) for instant HTTPS + automatic PWA install prompt on both Desktop and Mobile.
